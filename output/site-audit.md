# T1 · 사이트 감사 리포트 — finewave.kr

> **작성 상태: 접근 제약으로 인한 "감사 템플릿"**
> 이 산출물 세트를 제작한 실행 환경(Claude Code 샌드박스)의 **아웃바운드 네트워크 정책이 `finewave.kr` 접속을 차단**합니다.
> `finewave.kr`, `www.finewave.kr`, `archive.org`(웨이백) 모두 프록시 단에서 **403(policy denial)** 로 거부되었고, 헤드리스 크롬(Playwright)으로도 동일하게 막혔습니다.
> 따라서 **실측값(폰트/색상/셀렉터/이미지 URL)을 이 문서에 지어내지 않았습니다.** 대신, 운영자가 브라우저 개발자도구(F12)로 **10~15분 내에 직접 채울 수 있는 감사 템플릿**으로 작성했습니다.
> 채워진 값은 각 스니펫(T2~T8) 상단의 CSS 변수/플레이스홀더에 그대로 대입하면 됩니다.
>
> - 제작일: 2026-07-18
> - 대상: https://finewave.kr/ (WordPress 7.0 · Astra · Elementor 4.1.2 · Sticky Header Effects · WPForms Lite)
> - 측정 권장 환경: **Chrome, 1920×1080** (FRCCS 잘림 재현 해상도와 동일)

## 0. 운영자용 측정 방법 (공통)

각 항목 표의 "측정법" 열을 그대로 따라 하면 됩니다. 기본 도구:

| 작업 | 방법 |
|---|---|
| 요소 선택 | F12 → 좌상단 화살표 아이콘(⌘/Ctrl+Shift+C) → 대상 클릭 |
| 계산된 스타일 확인 | 우측 패널 **Computed** 탭 → `font-family`, `font-size`, `height`, `background-color` 검색 |
| 셀렉터 복사 | Elements 트리에서 요소 우클릭 → **Copy → Copy selector** |
| 이미지 원본 URL | 이미지 우클릭 → **Open image in new tab** → 주소창 URL 복사 / Network 탭 Img 필터 |
| 색상 HEX | Computed의 색상 스와치 클릭 → HEX 표기로 전환 |
| 헤더 높이 | 헤더 요소 선택 → Computed의 `height`, 또는 Elements 상단 박스모델의 세로 px |

> 💡 색상값은 **Elementor 사이트 설정 → 글로벌 색상**에도 정의돼 있을 가능성이 높습니다. 관리자 접근이 되면 그 값을 우선 사용하세요(이번 산출물 제작에는 관리자 접근 불필요/미사용).

| 타깃 섹션 id | 섹션의 `id` 속성 | `#____________` |
| 타깃 섹션 높이 | Computed `height` / `min-height` | `____` (예: `100vh`, `860px`) |
| 섹션 상단이 헤더에 가려지는가 | 앵커 클릭 후 육안 | ☐ 예(오프셋 문제) ☐ 아니오 |

> **판정 가이드(T4 분기):**
> - 도착 지점이 **헤더 높이만큼 위로 가려짐** → **오프셋 문제** → T4의 `scroll-margin-top` 해법 사용.
> - 섹션 `height:100vh` 인데 내용이 세로로 넘쳐 **아래가 잘림** → **섹션 높이 문제** → T4의 대안 B(`min-height`+`height:auto`) 사용.
> - 이 표의 "섹션 높이"와 "가려짐/잘림" 체크가 분기를 결정합니다.
